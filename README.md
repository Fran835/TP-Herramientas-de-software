# TP-Herramientas-de-software## Conclusión del análisis:

El dataset presenta una proporción significativa de inconsistencias de origen,
principalmente en formato de fecha/hora, patentes mal registradas y valores
faltantes en variables críticas para el cálculo de infracciones.

Después de normalizar y limpiar la información, se observa un patrón estable de
reincidencia en determinadas patentes, franjas horarias y ubicaciones,
lo que permite identificar focos de control prioritarios.

La depuración previa al análisis resulta indispensable para evitar sesgos y para
que los indicadores de exceso de velocidad sean confiables para su uso en un
sistema de fiscalización moderno.
